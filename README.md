## 📌 Project Overview

**Income Predictor Pro** is an end-to-end machine learning web application built to classify whether a person's annual income crosses the $50K threshold. The primary focus is creating a fully deployment-ready pipeline that handles end-to-end data processing, inference, and an interactive user interface.

---

## 📊 Dataset Details

The model is trained on the classic **UCI Adult / Census Income** dataset.
* **Total Records:** 32,561 rows and 15 columns.
* **Key Features:** `age`, `workclass`, `education`, `marital.status`, `occupation`, `race`, `sex`, `hours.per.week`, etc.
* **Target Variable:** `income` (`<=50K` or `>50K`).
